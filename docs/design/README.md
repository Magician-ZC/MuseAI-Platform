## 设计边界

- 普通用户功能优先放在桌面客户端中，通过“我的工作室 / 平台世界”双空间组织。
- 本地工作室不强制登录，也不依赖平台服务；平台世界在登录后解锁云端能力。
- 管理后台保持独立 Web 应用，只承载运营、审核、风控、指标、模型与 Prompt 治理等管理能力。
- 设计预览参数 `?design=preview` 仅用于开发环境验收，不代表正式数据源或正式鉴权被绕过。

- `admin-*`：后台参考图、最终页面及主监控区/诊断区对照图。
- 文件名以用途命名，不再使用生成工具产生的随机 ID。

## 维护规则

1. 页面结构、核心交互或视觉规范发生实质变化时，同步更新对应设计文档。
2. 新截图统一使用 1440 × 1024、设备像素比 1 的验收基线；响应式页面另补关键断点截图。
3. 设计参考、实现截图和并排对照图必须保存在仓库内，避免引用个人临时目录。
4. 文档必须区分“设计目标”“已实现”“代码推断”和“待验证”，不能把设计方案写成已上线能力。
5. 后续新增后台模块时复用现有外壳、色彩和密度规范，不为单页另造一套视觉系统。
